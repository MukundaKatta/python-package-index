MukundaKatta Python package index

A PEP 503 simple package index for the libraries below, hosted on GitHub Pages. Useful while waiting on PyPI rate-limit clearance, or when you need a guaranteed pin to artifacts published to GitHub Releases.

Install

pip install --index-url https://mukundakatta.github.io/python-package-index/simple/ \
    bedrock-ops embspec agent-budget

Or one at a time:

pip install --index-url https://mukundakatta.github.io/python-package-index/simple/ bedrock-ops

If the package needs runtime deps (e.g. boto3 for bedrock-ops, numpy for embspec), pip will fall through to PyPI for those — pass --extra-index-url https://pypi.org/simple/ if your environment is locked.

Why this exists

PyPI's "too many new projects created" cap fired when these three packages were submitted in quick succession and has stayed sticky for >24 hours, with admin review pending. This index lets users install the packages from their authoritative GitHub Release artifacts via standard pip tooling without waiting on PyPI.

When PyPI publishes complete, this index will continue working but installing from PyPI will be the canonical path.
